# Vietnamese UX Glossary Standard (KataCore)

Từ điển giúp AI Agent dịch hoặc đặt nhãn (Label), Placeholder chính xác cho người dùng Việt Nam.

## 1. Hành động (Actions/Buttons)

- `Create`/`Add New` ➔ **Thêm mới**, **Tạo mới**
- `Update`/`Edit` ➔ **Cập nhật**, **Chỉnh sửa**
- `Delete` ➔ **Xóa**
- `Confirm` ➔ **Xác nhận**
- `Cancel` ➔ **Hủy bỏ**
- `Save changes` ➔ **Lưu thay đổi**
- `Search` ➔ **Tìm kiếm**
- `Filter` ➔ **Lọc**
- `Export` ➔ **Xuất dữ liệu**
- `Import` ➔ **Nhập dữ liệu**
- `Sync` ➔ **Đồng bộ**
- `View Detail` ➔ **Xem chi tiết**
- `Quick View` ➔ **Xem nhanh**
- `Select` ➔ **Chọn**
- `Bulk Action` ➔ **Hành động khối**

## 2. Thông tin chung (General Fields)

- `Name` ➔ **Tên**, **Họ tên**
- `Full Name` ➔ **Họ và tên**
- `First Name` ➔ **Tên**
- `Last Name` ➔ **Họ**
- `Email` ➔ **Email (giữ nguyên)**
- `Phone` ➔ **Số điện thoại**, **SĐT**
- `Address` ➔ **Địa chỉ**
- `District` ➔ **Quận/Huyện**, **Quận**
- `Province`/`City` ➔ **Tỉnh/Thành**, **Tỉnh**
- `Ward` ➔ **Phường/Xã**
- `Notes` ➔ **Ghi chú**
- `Status` ➔ **Trạng thái**
- `Code`/`ID` ➔ **Mã**, **Mã định danh**
- `Type` ➔ **Loại**, **Phân loại**
- `Description` ➔ **Mô tả**
- `Created At` ➔ **Ngày tạo**
- `Updated At` ➔ **Ngày cập nhật**
- `Action` ➔ **Thao tác**

## 3. Nghiệp vụ Bán hàng & Đơn hàng (Sales & Orders)

- `Order Number`/`ID` ➔ **Mã đơn**, **Mã đơn hàng**
- `Customer` ➔ **Khách hàng**
- `Product` ➔ **Sản phẩm**
- `Category` ➔ **Danh mục**
- `Price` ➔ **Giá**, **Đơn giá**
- `Quantity` ➔ **Số lượng**, **SL**
- `Total` ➔ **Tổng tiền**, **Thành tiền**
- `Subtotal` ➔ **Tiền hàng**
- `Discount` ➔ **Giảm giá**, **Chiết khấu**
- `VAT`/`Tax` ➔ **Thuế**, **VAT**
- `Shipping` ➔ **Vận chuyển**, **Phí giao hàng**
- `Grand Total` ➔ **Tổng cộng**, **Tổng thanh toán**
- `Payment Status` ➔ **Thanh toán**, **Trạng thái thanh toán**
- `Delivery Date` ➔ **Ngày giao**, **Ngày giao hàng**

## 4. Trạng thái (Common Statuses)

- `Pending` ➔ **Đang chờ**, **Chờ xử lý**
- `Active` ➔ **Đang hoạt động**, **Hoạt động**
- `Inactive` ➔ **Ngừng hoạt động**, **Tạm dừng**
- `Processing` ➔ **Đang xử lý**
- `Completed` ➔ **Đã hoàn thành**, **Hoàn tất**
- `Cancelled` ➔ **Đã hủy**
- `Paid` ➔ **Đã thanh toán**
- `Unpaid` ➔ **Chưa thanh toán**
- `Partial` ➔ **Một phần**
- `Confirmed` ➔ **Đã xác nhận**

## 5. UI Components & Messages

- `Select...` ➔ **Chọn...**
- `Search...` ➔ **Tìm kiếm...**
- `No results found` ➔ **Không tìm thấy kết quả**
- `Loading...` ➔ **Đang tải...**
- `Success` ➔ **Thành công**
- `Error` ➔ **Lỗi**
- `Warning` ➔ **Cảnh báo**
- `Are you sure?` ➔ **Bạn có chắc chắn?**, **Xác nhận hành động**

---
**Lưu ý**: Tuyệt đối không để Text Tiếng Anh trên UI. Code name dùng Tiếng Anh, UI dùng Tiếng Việt.
